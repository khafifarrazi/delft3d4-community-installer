# 🤝 Panduan Kontribusi (Contributing Guidelines)

Terima kasih atas ketertarikan Anda untuk berkontribusi pada proyek pengemasan komunitas **Delft3D 4 Suite**!

---

## 💡 Bagaimana Anda Bisa Berkontribusi?

1. **Peningkatan Dokumentasi & Tutorial**:
   - Menulis panduan studi kasus baru, tips pembuatan grid kurvilinear dengan RGFGRID, interpolasi batimetri dengan QUICKIN, atau pemodelan hidrodinamika pantai/sungai dengan FLOW2D3D.
   - Memperbaiki kesalahan ketik atau memperjelas langkah-langkah di folder `docs/`.
2. **Peningkatan Skrip Installer**:
   - Menambahkan opsi bahasa baru pada installer Inno Setup.
   - Mengoptimalkan ukuran kompresi atau integrasi shortcut.
3. **Melaporkan Kendala**:
   - Melaporkan error instalasi atau bug dependensi melalui fitur GitHub Issues.

---

## 📜 Aturan Etika & Kepatuhan Lisensi

1. **Hormati Hak Cipta Deltares**: Semua kontribusi kode maupun dokumentasi tidak boleh menghapus atribusi hak cipta milik Stichting Deltares.
2. **Jangan Mengunggah Berkas Lisensi Pribadi**: Jangan pernah membuat Pull Request atau commit yang menyertakan file lisensi (`*.lic`) pribadi Anda.
3. **Jaga Kesopanan**: Berkomunikasi secara profesional dan saling mendukung sesama mahasiswa, peneliti, dan praktisi di komunitas pemodelan hidrodinamika.
