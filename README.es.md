## 📦 Contenido del Paquete Todo-en-Uno (All-in-One)

Este instalador integra todo el entorno de modelado numérico Delft3D 4:

1. **Delft3D 4 Menu e Interfaces de Módulos (4.07.02)**: La interfaz clásica de modelado para FLOW, WAVE, WAQ, PART y TIDE.
2. **Generadores de Malla y Batimetría**:
   * **RGFGRID**: Generador de mallas ortogonales curvilíneas para aguas costeras, estuarios y ríos.
   * **QUICKIN**: Herramienta de interpolación de profundidad, batimetría y rugosidad de fondo.
3. **Motores de Cálculo Numérico Completos de 64 bits (Kernels)**:
   * **Delft3D-FLOW (`flow2d3d.exe`)**: Solucionador hidrodinámico y morfodinámico.
   * **Delft3D-WAVE (`wave.exe` & SWAN)**: Modelado de oleaje por viento y transformación costera.
   * **Delft3D-WAQ (`delwaq.exe`)**: Simulación multidimensional de calidad del agua y ecología acuática.
   * **Delft3D-PART (`delpar.exe`)**: Rastreo de partículas para derrames de petróleo y dispersión.
4. **Herramienta QUICKPLOT 2.72 (Windows 64-bit)**: Visualizador avanzado para series temporales, vectores de corrientes y mapas.
5. **Configuración Automatizada de Licencia FlexNet**: Configura automáticamente el directorio (`C:\Program Files (x86)\DS_Flex`) y las entradas de registro.
